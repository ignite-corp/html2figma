# 개인정보 처리방침 (Privacy Policy) — html2figma

최종 수정일: 2026-07-08

html2figma는 웹페이지를 캡처해 Figma 디자인으로 변환하는 크롬 익스텐션 및 Figma 플러그인입니다.
본 문서는 확장 프로그램이 데이터를 어떻게 다루는지 설명합니다.

## 요약
- 캡처 데이터(페이지 내용)는 **저장하지 않습니다.** 릴레이 서버는 통과(중계)만 합니다.
- **무료 사용에는 계정이 필요 없으며**, 무료 사용자에 대해 어떤 개인정보도 수집하지 않습니다. 사용 횟수는 사용자의 브라우저 저장소(`chrome.storage`)에만 기록되며, 크롬 동기화를 켠 경우 본인 크롬 계정의 동기화 저장소를 통해 본인 기기 간에만 공유됩니다. 당사 서버로는 전송되지 않습니다.
- **Pro 구독을 구매·이용할 때만** Google 계정 로그인으로 최소한의 계정 정보(Google 사용자 ID, 이메일)와 구독 상태를 수집합니다.
- 결제 정보(카드번호 등)는 당사가 아닌 결제 처리사 **Paddle**(Merchant of Record)이 처리하며, 당사는 결제 수단 정보에 접근하지 않습니다.
- 분석/트래킹/광고 식별자를 일절 사용하지 않습니다.

## 수집·처리하는 데이터
| 데이터 | 처리 위치 | 저장 여부 |
|---|---|---|
| 현재 탭의 DOM·스타일·레이아웃(캡처 대상) | 사용자 기기(브라우저) | 저장 안 함 |
| 이미지/SVG 등 페이지 에셋 | 사용자 기기 | `.h2f` 파일로 사용자가 직접 저장 시에만 |
| 페어링 코드, 전송 설정(on/off) | 브라우저 `chrome.storage.local` / Figma `clientStorage` | 로컬에만 저장 |
| 무료 플랜 월간 사용 횟수 | 브라우저 `chrome.storage.sync`(+local) | 사용자 브라우저/본인 크롬 동기화에만 저장 (당사 서버 전송 없음) |
| **(Pro 로그인 시)** Google 사용자 ID, 이메일 | 당사 계정 서버(Cloudflare) | 저장 |
| **(Pro 구독 시)** 구독 상태, Paddle 고객/구독 ID | 당사 계정 서버(Cloudflare) | 저장 |

- Google 로그인은 신원 확인 전용 범위(`openid email profile`)만 요청하며, 이름·이메일·프로필 이미지 외의 정보에는 접근하지 않습니다.
- 로그인 시 Figma 액세스 토큰은 신원 확인 직후 폐기되며 저장하지 않습니다.

## 결제 (Pro 구독)
- 결제는 Merchant of Record 인 [Paddle.com](https://www.paddle.com)이 처리합니다. 카드번호 등 결제 수단 정보는 Paddle 만 취급하며, Paddle 의 개인정보 처리방침이 적용됩니다.
- 당사는 Paddle 로부터 구독 상태(활성/해지 등)와 고객·구독 식별자만 전달받아 Pro 자격 확인에 사용합니다.

## `chrome.debugger` 권한 사용 고지
정확한 스타일·레이아웃 추출을 위해 Chrome DevTools Protocol(`chrome.debugger`)로
현재 탭의 DOM 스냅샷을 읽습니다. 이 과정에서 Chrome은 "이 확장 프로그램이 디버깅하고 있습니다"
배너를 표시합니다. 읽어들인 데이터는 캡처·전송 목적 외로 사용되지 않으며 캡처 종료 시 `debugger`를 해제합니다.

## direct-send(페어링 릴레이) 사용 시
- 사용자가 익스텐션에서 플러그인이 발급한 6자리 코드를 입력해 전송할 때만 동작합니다.
- 캡처 데이터(`.h2f` JSON)는 릴레이 서버를 **통과만** 하며(WebSocket 중계), 서버는 이를 **디스크에 저장하지 않습니다.**
- 룸은 페어링 코드로 격리되어 같은 코드로 연결된 당사자끼리만 데이터를 주고받습니다.
- 릴레이는 유휴 시 자동 폐기(TTL)되며, 로그에 페이로드 내용을 남기지 않습니다.
- 공개 릴레이는 관리형 Node 호스팅(예: Render) 또는 Cloudflare Workers에서 전송 구간 TLS(`wss://`)로 운영됩니다.
