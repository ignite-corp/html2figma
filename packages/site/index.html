Features

디테일까지 그대로 옮깁니다

“대충 비슷하게”가 아니라, 픽셀과 스타일을 정확하게.

📐

픽셀 정확한 레이아웃

Chrome DevTools Protocol로 DOM 스냅샷을 읽어 위치·크기를 그대로 재현합니다. 그라디언트, 그림자, 비대칭 보더, 라운드 코너, overflow 클리핑까지.

✏️

진짜 편집 가능한 텍스트

폰트·두께·색·정렬이 살아있는 텍스트 노드로 도착합니다. 이미지 위 글자를 다시 타이핑할 필요가 없어요.

🧬

SVG → 벡터

인라인 SVG가 편집 가능한 벡터 노드로 변환됩니다.

🪆

iframe · Shadow DOM

중첩 프레임과 웹 컴포넌트도 병합해 한 번에 캡처합니다.

⚡

6자리 코드 direct-send

페어링 코드 하나로 익스텐션에서 Figma 플러그인으로 즉시 전송.

🧩

Auto Layout + Local Styles

붙여넣고 끝이 아니라, 작업할 수 있게. Auto Layout을 자동 구성하고 색·텍스트 스타일을 Local Styles로 만들어 드립니다.

🔒

기본은 로컬, 추적 없음

캡처 데이터는 기본적으로 내 기기 안에서만 처리됩니다. 분석·트래킹·광고 식별자 없음. direct-send 시에도 릴레이는 저장 없이 즉시 중계 후 폐기합니다.

FAQ

자주 묻는 질문

스크린샷 캡처 도구와 뭐가 다른가요?
스크린샷은 한 장의 이미지지만, html2figma는 페이지를 실제 Figma 프레임·텍스트·이미지·벡터 노드로 재구성합니다. 글자를 다시 타이핑하거나 트레이싱할 필요 없이 색상·문구·레이아웃을 바로 수정할 수 있어요.
캡처한 데이터는 어디로 가나요?
기본적으로 내 기기 안에서만 처리됩니다(파일 다운로드/클립보드). direct-send를 사용할 때만 릴레이 서버를 "통과"하며, 저장하지 않고 즉시 중계 후 폐기합니다. 무료 사용자의 개인정보는 수집하지 않습니다.
Figma 플러그인이 꼭 필요한가요?
네. 크롬 익스텐션이 캡처를 담당하고, Figma 쪽 html2figma 플러그인이 캡처 파일을 받아 실제 레이어로 그려줍니다. 둘 다 무료로 설치할 수 있어요.
Pro 구독은 어떻게 해지하나요?
언제든 해지할 수 있습니다. 결제는 Merchant of Record인 Paddle이 처리하며, 결제 영수증 메일의 링크에서 바로 구독을 관리할 수 있어요. 환불 정책은 여기를 참고하세요.
